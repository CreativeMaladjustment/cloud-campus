# cloud-campus
Bite-sized AWS examples and cloud deployment guides for quick reference.

## Examples

- [LocalStack Cloudflare Tunnel Demo](docs/localstack-tunnel.md) — deploy a hello-world Lambda to LocalStack and expose it publicly via a Cloudflare Quick Tunnel.
- [LocalStack Chat App via Cloudflare Tunnel](docs/localstack-chat-tunnel.md) — a username-only chat app (Lambda + DynamoDB) deployed to LocalStack and exposed via a Cloudflare Quick Tunnel.
- [LocalStack GitHub Actions Workflow](docs/localstack-github-actions-setup.md) — S3 bucket examples via CloudFormation, Terraform, and boto3, tested against LocalStack in CI.
